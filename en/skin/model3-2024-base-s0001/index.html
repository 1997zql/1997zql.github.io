Common questions

How many wraps can I store?
Paint Shop keeps every wrap you import, so you can switch between as many as you like — no hard limit.
Does it look the same on screen as in the preview?
The in-car display has a different colour gamut than a phone or monitor, so it reads slightly darker in person — that is normal.
What format does the USB drive need?
exFAT, FAT32 or ext4 all work; NTFS is not recognised. Create a folder named Wraps at the root and drop the PNG inside.
